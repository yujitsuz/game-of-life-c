Based on Conway's Game of Life system based on C. You can choose framerates and loops and two different initial states.

# Conway's Game of Life — C

Console-based Game of Life simulator built in C.

## Features
- Glider and Blinker + Block presets
- Toroidal (wraparound) borders
- Configurable FPS (1-60)
- Finite or infinite loop mode
- Flicker-free terminal rendering

## How to compile
gcc main.c -o game && ./game
